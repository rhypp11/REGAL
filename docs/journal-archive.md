# Journal archivé

Régal sert en priorité à gérer la Collection. Le suivi des parties se poursuit dans Google Sheets.

Le Journal peut être réactivé en passant `REGAL_JOURNAL_ENABLED` à `true` dans `index.html`. Ses données restent dans les sauvegardes complètes. Les liens existants sont conservés dans les données. Quand le module est en pause, la Collection affiche et laisse modifier son propre statut.

## Idée à reprendre plus tard

Une recherche de jeux indépendante du Journal permettrait de retrouver le titre, la bannière, l’icône carrée et les DLC connus, puis de copier les informations vers Google Sheets. Les jeux de la Collection pourraient servir de première source. Un catalogue externe couvrirait les titres absents.
